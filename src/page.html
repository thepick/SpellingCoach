                  Import terms, definitions, and images

                  CSV format and adding images

                  Use one row per term, with a term column and a definition column. Add an optional image column containing the image filename. Up to 200 terms per set.

                  termdefinitionimage
                  evaporationThe change from liquid water into water vapor.evaporation.png
                  condensationThe change from water vapor into liquid water.condensation.png
                  1. Save your spreadsheet as CSV or TSV, or copy its rows and paste them below.
                  2. Upload the terms file, then select all of its image files using Add image files. The image column must match each filename, including its extension.
                  3. Alternatively, upload a ZIP containing terms.csv and the images. If pictures are in an images folder, write a path such as images/evaporation.png in the CSV.
                  4. Review the preview, fix any highlighted rows, then save. Approve the vocabulary before creating or updating a student link.

                  Images are optional. JPEG, PNG, and still WebP are accepted, up to 10 MB per original image. WordLab resizes them for students. Use filenames rather than web links. Images appear beside definitions; students can tap them to enlarge.

                  Optional columns: image_alt (a short picture description), part_of_speech, image_source, image_credit, and image_license. Do not put the answer in a picture description intended for practice.

                  CSV tip: put text containing a comma inside double quotes, for example "Water that falls as rain, snow, sleet, or hail.". Spreadsheet apps normally handle this when saving as CSV.
