# WordLab invited teachers and prepared audio

Approved scope: invitation-only teachers bring their own Groq and optional OpenRouter keys; automatic word WAVs after saving; optional vocabulary drafting plus full-example and blank-question WAVs; private preparation, review, reliable sharing, and reuse. Student replay never generates AI requests. Existing owner login, packs and student links remain usable.

Architecture: retain the existing Cloudflare Worker and SQLite Durable Object. Add stable teacher identities and ownership checks, single-use expiring invitations, password hashing, encrypted per-teacher provider credentials, and private saved sets with background audio preparation. Existing owner login is the administrator and owns legacy content. Ordinary teachers cannot access operator controls or use server provider keys. Only their own provider keys fund their work. No new dependencies.

Teacher flow: invitation URL -> choose username/display name/password -> connect Groq and optionally OpenRouter -> paste/save set -> word audio queues privately -> share spelling when ready -> optionally Add vocabulary sentences + audio -> automatically save generated drafts -> review and approve -> share vocabulary/mixed. Saved sets reload for the same teacher across browsers. Status identifies each pending/failed recording; retry missing clips only. Edits invalidate matching text only, preserve successful old clips for unchanged text. Read full examples in study; answer questions with masked audio. Groq Troy is primary; OpenRouter text fallback uses free models by default. Paid text and alternate-voice audio fallback require explicit per-teacher opt-in. Never use another teacher's key. Prefer wait/retry to preserve Troy. Report unavailable fallback rather than pretend support.

Security: cryptographic single-use invitation secrets stored hashed, username uniqueness, salted PBKDF2 password hashes, rate-limited auth, revocable teacher sessions, separate administrator role. AES-GCM credentials bound to teacher/provider with a dedicated encryption secret outside SQLite. No raw keys in responses, jobs, packs, logs or exports. Generation and quota ownership comes from authenticated identity, never request owner parameters. Recheck identity/credential state after awaits before saving. Teacher revocation stops future/background generation; public published playback may remain available. Host is trusted to decrypt keys for provider calls and pays hosting/storage. No email sending required: administrator copies invitation link.

## Shared API contract
- POST /api/teacher/login {username,password}; POST /api/teacher/accept {invite,username,name,password}: {token,expiresAt,teacher:{id,name,username,isAdmin},config}.
- GET /api/teacher/profile: {teacher,config,keys:{groq:boolean,openrouter:boolean},settings:{allowPaidText:boolean,allowAlternateAudio:boolean}}.
- PUT /api/teacher/keys {groq?:string|null,openrouter?:string|null,allowPaidText?:boolean,allowAlternateAudio?:boolean}: same profile response. Empty omitted means unchanged; null deletes. Server-side connection status, no automatic paid validation calls.
- POST /api/admin/invitations {label}: {id,invite,expiresAt}; GET /api/admin/invitations: {invitations}; POST /api/admin/revokeinvite {id}; GET /api/admin/teachers: {teachers}; POST /api/admin/revoketeacher {id}.
- POST /api/teacher/sets {pack}: private upsert of saved pack (draft vocabulary allowed), return {pack,audio,audioStatus}. GET /api/teacher/sets: {sets}; GET /api/teacher/sets/:id: {pack,audio,audioStatus}; POST /api/teacher/sets/:id/retry; GET /api/teacher/sets/:id/audio/:prompt: authenticated WAV.
- audioStatus keeps ready,total,pending and adds recordings:[{key,word,text,status,error?,provider?,voice?}],retryAt?,message?. Public pack audioStatus excludes private error/provider details as needed.
- Keep existing /generate,/jobs and /admin/publish,/admin/packaudioqueue endpoints but scope their ordinary-teacher operations to stable identity; administrator-only settings/classes/invitations must reject ordinary teachers. Published info config based on authenticated credentials. Private-to-public transfer reuses existing clips.
- Learning.practiceAudioPrompts(record,index) preserves s/v keys and adds eN keys for full approved/draft examples, skill:'study'. Study sentences never play as answer hints during blank practice. Mode spelling prepares s; vocabulary/mixed also study and vocabulary clips. Draft private sets prepare all available prompts.
