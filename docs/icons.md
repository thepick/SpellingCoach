# Spelling Coach icons

The flat icon uses a white S and a mint check badge on blue-purple.
Created with the built-in image generation tool; resized with Lanczos sampling.
Apple icons are opaque squares; the device applies its own corner mask.

| Use | Files / square sizes |
| --- | --- |
| Browser tabs | favicon.ico (16, 32, 48, 64 px); matching PNG exports |
| Apple touch icons | 120, 152, 167, 180 px (180 px is apple-touch-icon.png) |
| Other device/browser icons | android-chrome-192x192.png; android-chrome-512x512.png |
| Reusable master | spellingcoach-icon-1024.png |

Both HTML entry pages link to the icon set and site.webmanifest.
The manifest keeps browser display mode; it does not add offline support.
To add the site on an iPad, open it in Safari and use Share > Add to Home Screen.
Previously saved shortcuts may need to be recreated to receive the new icon.

Reference: [Apple touch icon configuration](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)
and [web app manifest icons](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/icons).

## Image generation prompt

Edit the original Spelling Coach icon into a flat favicon/app icon. Preserve the
bold white S and mint circular badge with navy check at the lower right. Remove
reflections, highlights, sheen, gradients, texture, bevels, glow and shadows.
Use solid blue-purple #465BD5, white, mint #56DFA3, and navy #142042.
Make the background an opaque square extending to all edges, without rounded
corners or external margins; the operating system will round it. Keep the symbol
inside the edges, with simple bold shapes and no additional wording or mockup.
